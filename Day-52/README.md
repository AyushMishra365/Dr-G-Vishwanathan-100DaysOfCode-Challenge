## Problem 1: Camelcase Matching

**Approach:**
- Used two pointers to compare each query with the given pattern.
- Advanced both pointers when characters matched.
- Allowed extra lowercase characters in the query while rejecting unexpected uppercase characters.
- Added the matching result for every query to the answer list.

**Time Complexity:** O(n × m)

**Space Complexity:** O(1) (excluding output list)

**Performance**
- Runtime: **1 ms** (Beats **30.66%**)
- Memory: **43.05 MB** (Beats **41.61%**)

## Problem 2: Print Words Vertically

**Approach:**
- Split the sentence into individual words.
- Found the maximum word length.
- Built each vertical string column by column.
- Removed trailing spaces before adding each string to the answer.

**Time Complexity:** O(n × m)

**Space Complexity:** O(n × m)

**Performance**
- Runtime: **1 ms** (Beats **91.77%**)
- Memory: **43.37 MB** (Beats **22.78%**)
