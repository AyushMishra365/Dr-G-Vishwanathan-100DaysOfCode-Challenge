## Problem Statement

Given two strings `a` and `b`, determine whether it is possible to split them at the same index and combine one prefix with the other suffix to form a palindrome.

---

## Example 1

### Input

```text
a = "x"
b = "y"
```

### Output

```text
true
```

---

## Example 2

### Input

```text
a = "abdef"
b = "fecab"
```

### Output

```text
true
```
