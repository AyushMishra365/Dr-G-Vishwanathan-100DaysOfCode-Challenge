## Problem Statement

Given a string consisting of words and spaces, return the length of the last word in the string.

---

## Example 1

### Input

```text
s = "Hello World"
```

### Output

```text
5
```

---

## Example 2

### Input

```text
s = "   fly me   to   the moon  "
```

### Output

```text
4
```

---

## Constraints

```text
1 <= s.length <= 10⁴

s consists of English letters and spaces.
```
