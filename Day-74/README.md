## Problem Solved

### LeetCode
- 1160. Find Words That Can Be Formed by Characters (Easy)

---

## Key Learnings

- Practiced using **frequency counting** to determine whether a word can be formed from the available characters.
- Used a fixed-size array of `26` elements to store the frequency of lowercase English letters.
- Learned how to compare the character frequencies of each word with the available character frequencies.
- Reinforced the concept of checking each word independently and adding its length only when it can be completely formed.
