### Problems Overview

#### 435. Non-overlapping Intervals

Used a greedy strategy by sorting intervals according to their ending times and counting overlapping intervals that needed to be removed.

#### 1295. Find Numbers with Even Number of Digits

Counted the digits of each number mathematically and checked whether the digit count was even.

#### 344A. Magnets

Traversed the sequence and counted how many times adjacent magnets differed, which directly represented the number of groups formed.
