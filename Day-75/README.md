## Problems Solved:

### 1. 3090. Maximum Length Substring With Two Occurrences

**Problem:**  
Find the maximum length of a substring where each character occurs at most twice.

**My Approach:**  
Used the **Sliding Window** technique with a frequency array. Expand the right pointer and increase the character count. Whenever a character occurs more than twice, move the left pointer forward until the window becomes valid again.

**Complexity:**  
- Time Complexity: O(n)
- Space Complexity: O(1)

### 2. 36. Valid Sudoku

**Problem:**  
Determine whether a 9 × 9 Sudoku board is valid by checking that digits do not repeat in any row, column, or 3 × 3 sub-box.

**My Approach:**  
Used frequency arrays to validate the rows, columns, and 3 × 3 sub-boxes separately. If any digit appears more than once in any of these sections, the board is invalid.

**Complexity:**  
- Time Complexity: O(1)
- Space Complexity: O(1)
