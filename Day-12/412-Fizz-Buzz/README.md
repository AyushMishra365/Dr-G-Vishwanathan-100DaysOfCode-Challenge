## Problem Statement

Given an integer `n`, return a string array where:

- Multiples of 3 → `"Fizz"`
- Multiples of 5 → `"Buzz"`
- Multiples of both → `"FizzBuzz"`
- Otherwise → the number itself

---

## Example

### Input

```text
n = 5
```

### Output

```text
["1","2","Fizz","4","Buzz"]
```
