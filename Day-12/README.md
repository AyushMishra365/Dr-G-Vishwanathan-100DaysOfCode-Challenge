### Problems Overview

#### 112A. Petya and Strings

A string comparison problem involving case-insensitive lexicographical ordering.

**My Approach**

- Used Java's built-in case-insensitive string comparison method.
- Compared both strings without worrying about character case.
- Returned the result according to the comparison outcome.

**What I Learned**

This problem highlighted how useful built-in language features can be when solving implementation-based questions. Instead of manually converting and comparing characters, Java already provides methods that handle the task efficiently.

**Complexity**

- Time Complexity: O(n)
- Space Complexity: O(1)

---

#### 412. Fizz Buzz

A classic implementation problem based on divisibility conditions.

**My Approach**

- Iterated through the numbers from 1 to n.
- Used conditional checks to determine whether a number was divisible by 3, 5, or both.
- Added `"Fizz"`, `"Buzz"`, `"FizzBuzz"`, or the number itself to the result accordingly.

**What I Learned**

Although the problem is simple, it serves as a good reminder that the order of conditions matters. Checking divisibility correctly is essential for producing the expected output.

**Complexity**

- Time Complexity: O(n)
- Space Complexity: O(n)
