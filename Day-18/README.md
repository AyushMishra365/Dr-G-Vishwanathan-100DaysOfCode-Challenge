### Problems Overview

#### 96A. Football

A string processing problem involving detection of dangerous situations.

**My Approach**

- Traversed the string while counting consecutive identical characters.
- Reset the counter whenever the sequence broke.
- Printed "YES" as soon as seven consecutive players from the same team were found.

**What I Learned**

Maintaining a running count is often more efficient than repeatedly checking substrings.

**Complexity**

- Time Complexity: O(n)
- Space Complexity: O(1)

---

#### 231A. Team

A counting and implementation problem.

**My Approach**

- Read each team's confidence values.
- Counted how many problems had at least two members confident about the solution.
- Incremented the answer whenever the sum of the three values was at least two.

**What I Learned**

Many implementation problems can be solved by translating the statement directly into code without needing advanced techniques.

**Complexity**

- Time Complexity: O(n)
- Space Complexity: O(1)
