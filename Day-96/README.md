## 📌 Problems Solved

### 🔹 LeetCode 3903 – Smallest Stable Index I
- Used a suffix minimum array to efficiently find the minimum value from each index to the end.
- Traversed the array while maintaining the maximum value from the beginning.
- Checked whether the difference between the prefix maximum and suffix minimum is at most `k`.
- Returned the first index satisfying the stability condition.

## 🔑 Key Learnings

- Prefix and suffix techniques can simplify range-based calculations.
- A suffix minimum array helps answer minimum-from-index queries efficiently.
- Maintaining a running prefix maximum avoids repeatedly scanning the left side.
- Combining prefix and suffix information can reduce unnecessary nested traversal.
