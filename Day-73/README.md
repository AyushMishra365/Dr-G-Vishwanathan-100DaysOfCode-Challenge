**## Problem Statement**

You are given two strings `s` and `t`.

String `t` is generated by randomly shuffling string `s` and then adding one more letter at a random position.

Return the letter that was added to `t`.

---

**## My Approach**

**### Idea**

- Calculate the sum of the character values of all characters in `t`.
- Calculate the sum of the character values of all characters in `s`.
- Since `t` contains all characters of `s` plus one extra character, subtracting the sum of `s` from the sum of `t` gives the character value of the added letter.
- Convert the resulting integer back to a `char` and return it.
