## Problem Statement

Convert a string into a zigzag pattern on a given number of rows and then read the pattern row by row.

---

## Example 1

### Input

```text
s = "PAYPALISHIRING"
numRows = 3
```

### Output

```text
PAHNAPLSIIGYIR
```

---

## Example Pattern

```text
P   A   H   N
A P L S I I G
Y   I   R
```
