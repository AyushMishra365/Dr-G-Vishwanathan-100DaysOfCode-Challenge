## Problem Statement

Given an integer array `nums`, return `true` if any value appears at least twice in the array, and return `false` if every element is distinct.

---

## Example 1

### Input

```text
nums = [1,2,3,1]
```

### Output

```text
true
```

---

## Example 2

### Input

```text
nums = [1,2,3,4]
```

### Output

```text
false
```

---

## Constraints

```text
1 <= nums.length <= 10⁵

-10⁹ <= nums[i] <= 10⁹
```
