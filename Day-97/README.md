## 📌 Problems Solved

### 🔹 LeetCode 3904 – Smallest Stable Index II

- Solved the problem using a suffix minimum array.
- Maintained the maximum value from the beginning of the array while traversing each index.
- Checked whether the instability score satisfies the condition `max - suffixMin[i] <= k`.
- Returned the smallest stable index, or `-1` if no stable index exists.

## 🔑 Key Learnings

- Efficiently combining prefix and suffix information.
- Using a suffix minimum array for constant-time range minimum queries.
- Maintaining a running maximum during array traversal.
- Applying the same core idea to a harder variation of the stable-index problem.

## 🧠 Concepts Practiced
