### Problem Overview

#### 43. Multiply Strings

Simulated the multiplication process taught in elementary mathematics. Every digit of the first number was multiplied with every digit of the second number, and the partial products were accumulated in a result array. Finally, leading zeroes were skipped to construct the answer as a string.
