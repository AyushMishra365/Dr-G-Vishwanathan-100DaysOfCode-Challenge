## Takeaways

- Pascal's Triangle follows a simple recurrence where each element is the sum of the two elements directly above it.
- Instead of generating the entire triangle, it is sufficient to iteratively build rows until reaching the required index.
- Updating one row at a time is both simple and memory-efficient.
- This problem reinforces how dynamic programming can be applied even to straightforward mathematical patterns.

### Problem Overview

#### 119. Pascal's Triangle II

Generate only the required row of Pascal's Triangle without storing the complete triangle. Starting from the first row, construct each subsequent row using the values from the previous one until reaching the desired row index.
