## Problem 1: Flipping an Image

**Approach:**
- Traversed each row using two pointers from both ends.
- Simultaneously flipped the row horizontally and inverted the bits in a single pass.
- Used XOR with `1` to efficiently invert the binary values.

**Time Complexity:** O(n²)

**Space Complexity:** O(1)

**Performance**
- Runtime: **0 ms** (Beats **100.00%**)
- Memory: **45.56 MB** (Beats **87.41%**)
