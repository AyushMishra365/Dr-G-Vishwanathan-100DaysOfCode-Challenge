## Takeaways

- Dynamic Programming doesn't always require extra memory—sometimes only the current state is enough.
- Simple string traversal can solve many greedy problems without additional data structures.
- Looking for local patterns often leads to globally optimal solutions.

#### A. Stones on the Table
