## Problem Statement

Given an integer array `nums`, return all unique triplets `[nums[i], nums[j], nums[k]]` such that:

```text
i != j
i != k
j != k
```

and

```text
nums[i] + nums[j] + nums[k] == 0
```

---

## Example 1

### Input

```text
nums = [-1,0,1,2,-1,-4]
```

### Output

```text
[[-1,-1,2],[-1,0,1]]
```

---

## Example 2

### Input

```text
nums = [0,1,1]
```

### Output

```text
[]
```
