## Problem Statement

Given an integer array `nums` and an integer `target`, find three integers in `nums` such that the sum is closest to `target`.

Return the sum of the three integers.

---

## Example 1

### Input

```text
nums = [-1,2,1,-4]
target = 1
```

### Output

```text
2
```

---

## Example 2

### Input

```text
nums = [0,0,0]
target = 1
```

### Output

```text
0
```

---

## Constraints

```text
3 <= nums.length <= 500

-1000 <= nums[i] <= 1000

-10⁴ <= target <= 10⁴
```
