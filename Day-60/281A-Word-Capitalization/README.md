## Problem Statement

Given a word, capitalize only its first letter while leaving all remaining letters unchanged.

---

## My Approach

### Idea

- Read the input string.
- Convert the first character to uppercase using `Character.toUpperCase()`.
- Append the remaining substring as it is.
