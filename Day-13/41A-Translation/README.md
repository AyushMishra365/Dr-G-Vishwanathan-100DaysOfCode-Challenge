## Problem Statement

Given two strings, determine whether the second string is the reverse of the first string.

Print:

```text
YES
```

if it is a valid translation, otherwise print:

```text
NO
```

---

## Example

### Input

```text
code
edoc
```

### Output

```text
YES
```

---

## Constraints

```text
1 ≤ length of strings ≤ 100
```
