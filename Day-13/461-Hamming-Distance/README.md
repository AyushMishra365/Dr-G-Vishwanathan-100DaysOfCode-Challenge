## Problem Statement

The Hamming distance between two integers is the number of positions at which the corresponding bits are different.

Return the Hamming distance between two given integers.

---

## Example

### Input

```text
x = 1
y = 4
```

### Output

```text
2
```

### Explanation

```text
1 = 001
4 = 100

Differing positions = 2
```

---

## Constraints

```text
0 ≤ x, y ≤ 2³¹ - 1
```
