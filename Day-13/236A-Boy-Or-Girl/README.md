## Problem Statement

Count the number of distinct characters in the username.

If the count is even, print:

```text
CHAT WITH HER!
```

Otherwise print:

```text
IGNORE HIM!
```

---

## Example

### Input

```text
wjmzbmr
```

### Output

```text
CHAT WITH HER!
```

---

## Constraints

```text
1 ≤ length ≤ 100
```
