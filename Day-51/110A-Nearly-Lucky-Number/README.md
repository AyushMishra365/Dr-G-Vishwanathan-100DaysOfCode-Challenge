## My Approach

- Traversed the number as a string.
- Counted the digits `4` and `7`.
- Printed **YES** if the count was either `4` or `7`; otherwise printed **NO**.

### Complexity

```text
Time Complexity : O(n)

Space Complexity: O(1)
```
