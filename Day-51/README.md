## Problem 1: Maximize Active Section with Trade I

**Approach:**
- Counted the total active ('1') sections in the original string.
- Traversed every valid block of consecutive `1`s surrounded by `0`s.
- Calculated the inactive sections on both sides that could be activated after performing one trade.
- Updated the maximum possible active sections across all valid trades.

**Time Complexity:** O(n²)

**Space Complexity:** O(1)

**Performance**
- Runtime: **131 ms** (Beats **36.62%**)
- Memory: **47.82 MB** (Beats **83.10%**)

## Problem 2: Codeforces 791A - Bear and Big Brother

**Approach:**
- Simulated each passing year.
- Multiplied Limak's weight by 3 and Bob's weight by 2 until Limak became heavier.
- Counted the number of years required.

**Time Complexity:** O(years)

**Space Complexity:** O(1)

## Problem 3: Codeforces 110A - Nearly Lucky Number

**Approach:**
- Counted the occurrences of digits `4` and `7`.
- Checked whether the count itself was either `4` or `7`.
- Printed the required answer accordingly.

**Time Complexity:** O(n)

**Space Complexity:** O(1)

---

## Problem 4: Codeforces 486A - Calculating Function

**Approach:**
- Observed the mathematical pattern instead of simulating the series.
- Used the direct formula:
  - Even `n` → `n / 2`
  - Odd `n` → `-(n + 1) / 2`

**Time Complexity:** O(1)

**Space Complexity:** O(1)
