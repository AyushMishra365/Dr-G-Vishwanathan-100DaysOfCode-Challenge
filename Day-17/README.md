### Problems Overview

#### 242. Valid Anagram

A string comparison problem involving rearrangement of characters.

**My Approach**

- Converted both strings into character arrays.
- Sorted both arrays.
- Compared every character position to verify equality.

**What I Learned**

Sorting is often a simple and effective way to determine whether two strings contain exactly the same characters.

**Complexity**

- Time Complexity: O(n log n)
- Space Complexity: O(n)

---

#### 535B. Tavas and SaDDas

A number theory and pattern recognition problem involving lucky numbers.

**My Approach**

- Treated digit `4` as binary `0` and digit `7` as binary `1`.
- Built the corresponding binary value.
- Added all lucky numbers having fewer digits to determine the final position.

**What I Learned**

Many Codeforces problems hide mathematical or binary patterns behind seemingly unrelated statements.

**Complexity**

- Time Complexity: O(n)
- Space Complexity: O(1)
