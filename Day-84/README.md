## Problems Solved:

### 1. 1927. Sum Game

**Problem:**  
Determine whether Alice will win a game where players replace `?` characters in a digit string with digits from `0` to `9`. Alice wins if the final digit sums of the two halves are not equal.

**My Approach:**  
Used the expected value of each `?` character, which is `4.5`, since every digit from `0` to `9` is equally possible. I calculated the difference between the expected sums of the two halves. If the difference is not zero, Alice can force the sums to be unequal; otherwise, Bob wins.

**Complexity:**  
- Time Complexity: O(n)
- Space Complexity: O(1)
