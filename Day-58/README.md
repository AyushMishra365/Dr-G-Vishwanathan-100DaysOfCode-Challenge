## Problem 1: Arrival of the General

**Approach:**
- Traversed the array once to find the leftmost tallest soldier and the rightmost shortest soldier.
- Calculated the swaps needed to bring the tallest soldier to the front and the shortest soldier to the end.
- If moving the tallest soldier crosses the shortest soldier's original position, reduced the total swaps by one.

**Time Complexity:** O(n)

**Space Complexity:** O(1)

**Performance**
- Verdict: **Accepted**
- Time: **624 ms**
- Memory: **2596 KB**

---

## Day 58 Takeaways

- Learned how choosing the correct occurrence (leftmost maximum and rightmost minimum) minimizes swaps.
- Practiced solving array manipulation problems using index calculations instead of performing actual swaps.
- Reinforced handling overlapping movements through careful case analysis.
