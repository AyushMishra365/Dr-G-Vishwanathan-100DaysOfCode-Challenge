## Problem Statement

Your friend is typing their name into a keyboard.

Sometimes, when typing a character, the key might get long pressed and the character will be typed one or more extra times.

Determine if `typed` could be a long-pressed version of `name`.

---

## Example 1

### Input

```text
name = "alex"
typed = "aaleex"
```

### Output

```text
true
```

---

## Example 2

### Input

```text
name = "saeed"
typed = "ssaaedd"
```

### Output

```text
false
```
