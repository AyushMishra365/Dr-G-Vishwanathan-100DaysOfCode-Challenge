## Problem Statement

Given the array of integers `nums`, choose two different indices and return the maximum value of:

```text
(nums[i] - 1) * (nums[j] - 1)
```

---

## Example 1

### Input

```text
nums = [3,4,5,2]
```

### Output

```text
12
```
