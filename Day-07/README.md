### Problems Overview

#### 1051. Height Checker

A problem that requires determining how many students are standing in positions different from their expected sorted order.

**My Approach**

- Created a sorted version of the array.
- Compared the original array with the sorted array.
- Counted the positions where the values differed.

**What I Learned**

Sorting can often transform a problem into a simple comparison task, making the solution much easier to implement.

**Complexity**

- Time Complexity: O(n log n)
- Space Complexity: O(n)

---

#### 1464. Maximum Product of Two Elements in an Array

An array problem focused on finding the maximum possible product using two elements.

**My Approach**

- Identified the two largest elements in the array.
- Applied the required formula using those values.
- Returned the resulting product.

**What I Learned**

Sometimes the most efficient solution comes from identifying the key values needed instead of evaluating every possible combination.

**Complexity**

- Time Complexity: O(n)
- Space Complexity: O(1)

---

#### 976. Largest Perimeter Triangle

A problem that requires finding the largest perimeter that can be formed using three side lengths.

**My Approach**

- Sorted the array.
- Checked groups of three consecutive sides.
- Applied the triangle inequality property to determine whether a valid triangle could be formed.
- Returned the first valid perimeter encountered.

**What I Learned**

This problem highlighted how mathematical observations and sorting can work together to simplify a solution.

**Complexity**

- Time Complexity: O(n log n)
- Space Complexity: O(1)
