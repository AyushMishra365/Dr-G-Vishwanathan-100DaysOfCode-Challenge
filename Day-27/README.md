- Initializing DP states correctly is just as important as defining the transition.
- Trying every possible perfect square for each number guarantees the minimum answer.

### Problem Overview

#### 279. Perfect Squares

Given an integer `n`, determine the minimum number of perfect square numbers whose sum equals `n`.

The solution builds a DP array where each index stores the minimum number of perfect squares needed to form that value.
