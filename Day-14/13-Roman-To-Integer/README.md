## Problem Statement

Convert a Roman numeral into its integer representation.

Roman numerals are represented using:

```text
I = 1
V = 5
X = 10
L = 50
C = 100
D = 500
M = 1000
```

Special subtraction rules apply:

```text
IV = 4
IX = 9
XL = 40
XC = 90
CD = 400
CM = 900
```

---

## Example 1

### Input

```text
III
```

### Output

```text
3
```

---

## Example 2

### Input

```text
LVIII
```

### Output

```text
58
```

---

## Example 3

### Input

```text
MCMXCIV
```

### Output

```text
1994
```
