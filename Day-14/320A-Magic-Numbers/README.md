## Problem Statement

A number is considered magic if it consists only of the digits:

```text
1
14
144
```

in any valid sequence.

Determine whether the given number is magic.

Print:

```text
YES
```

or

```text
NO
```

---

## Example

### Input

```text
114114
```

### Output

```text
YES
```

---

## Example

### Input

```text
441231
```

### Output

```text
NO
```

---

## Constraints

```text
1 ≤ length ≤ 10
```
