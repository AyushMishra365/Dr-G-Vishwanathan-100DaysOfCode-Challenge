### Problems Overview

#### 71A. Way Too Long Words

A string processing problem that involves shortening long words according to a specific format.

**My Approach**

- Checked whether the length of a word exceeded 10 characters.
- If it did, replaced the middle characters with their count.
- Kept the first and last characters unchanged.

**What I Learned**

The problem itself was straightforward, but it highlighted how important it is to carefully follow the required output format.

Even simple implementation problems can lead to wrong answers if small details are overlooked.

**Complexity**

- Time Complexity: O(n)
- Space Complexity: O(1)

---

#### 131A. cAPS lOCK

A string manipulation problem that requires correcting words typed with an incorrect Caps Lock state.

**My Approach**

- Checked whether all characters except possibly the first were uppercase.
- If the condition was satisfied, toggled the case of every character.
- Otherwise, returned the word unchanged.

**What I Learned**

This problem required careful observation of patterns within the string rather than complex logic.

Once the condition was identified correctly, the implementation became quite simple.

**Complexity**

- Time Complexity: O(n)
- Space Complexity: O(n)
