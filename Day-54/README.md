## Problem 1: Nth Digit

**Approach:**
- Determined the digit-length group in which the required digit lies (1-digit, 2-digit, 3-digit numbers, and so on).
- Reduced `n` by the total digits in each group until reaching the correct range.
- Calculated the exact number containing the required digit.
- Converted that number to a string and returned the corresponding digit.

**Time Complexity:** O(log n)

**Space Complexity:** O(1)

**Performance**
- Runtime: **0 ms** (Beats **100.00%**)
- Memory: **42.18 MB** (Beats **40.64%**)
