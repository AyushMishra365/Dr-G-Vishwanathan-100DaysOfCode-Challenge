# Day 49 - Dr. G. Viswanathan 100 Days of Code Challenge

## Problems Solved

### 1. LeetCode 198 - House Robber (Medium)

**Approach:**
- Used Dynamic Programming.
- Maintained a DP array where each index stores the maximum money that can be robbed up to that house.
- For every house, either rob the current house (and add the value from two houses back) or skip it and keep the previous maximum.

**Time Complexity:** O(n)

**Space Complexity:** O(n)

**Performance**
- Runtime: **0 ms** (Beats **100.00%**)
- Memory: **42.63 MB** (Beats **75.22%**)

### 2. Codeforces 136A - Presents (800)

**Approach:**
- Created a reverse mapping of the given gift assignments.
- If friend `i` gave a gift to friend `p[i]`, stored `i` at index `p[i]`.
- Printed the resulting array.

**Time Complexity:** O(n)

**Space Complexity:** O(n)

**Verdict:** Accepted
