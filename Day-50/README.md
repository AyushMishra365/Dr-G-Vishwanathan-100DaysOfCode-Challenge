# Day 50 - Dr. G. Viswanathan 100 Days of Code Challenge

## Problems Solved

### 1. LeetCode 1260 - Shift 2D Grid (Easy)

**Approach:**
- Treated the 2D grid as a single linear array.
- Calculated the new position of each element after `k` shifts using modulo arithmetic.
- Converted the new linear index back into row and column indices and placed the element in a new grid.
- Finally converted the shifted grid into the required `List<List<Integer>>` format.

**Time Complexity:** O(m × n)

**Space Complexity:** O(m × n)

**Performance**
- Runtime: **5 ms** (Beats **83.45%**)
- Memory: **47.27 MB** (Beats **44.14%**)
