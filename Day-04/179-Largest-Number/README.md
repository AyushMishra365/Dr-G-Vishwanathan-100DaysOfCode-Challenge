## Problem Statement

Given a list of non-negative integers `nums`, arrange them such that they form the largest possible number and return it as a string.

---

## Example 1

### Input

```text
nums = [10,2]
```

### Output

```text
"210"
```

---

## Example 2

### Input

```text
nums = [3,30,34,5,9]
```

### Output

```text
"9534330"
```

---

## Constraints

```text
1 <= nums.length <= 100

0 <= nums[i] <= 10⁹
```
