## Problem Statement

Determine whether a watermelon of weight **w** can be split into two positive even parts.

---

## My Approach

### Idea

A valid split exists only if the weight is even and greater than 2.

### Steps

1. Read the weight.
2. Check if it is even.
3. Ensure it is greater than 2.
4. Print **YES** if both conditions hold; otherwise print **NO**.
