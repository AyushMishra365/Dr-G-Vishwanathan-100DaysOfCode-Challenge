## Problems Solved:

### 1. 657. Robot Return to Origin

**Problem:**  
Determine whether a robot returns to the origin `(0, 0)` after performing a sequence of moves represented by `U`, `D`, `L`, and `R`.

**My Approach:**  
Used four counters to track the number of upward, downward, left, and right movements. After traversing the string, I checked whether the number of `U` moves equals `D` moves and the number of `L` moves equals `R` moves. If both conditions are satisfied, the robot returns to the origin.

**Complexity:**  
- Time Complexity: O(n)
- Space Complexity: O(1)
