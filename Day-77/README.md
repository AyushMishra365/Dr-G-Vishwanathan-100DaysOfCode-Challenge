## Problems Solved:

### 1. 26. Remove Duplicates from Sorted Array

**Problem:**  
Given a sorted array, remove duplicates in-place so that each unique element appears only once and return the number of unique elements.

**My Approach:**  
Used the **Two Pointer** technique. One pointer keeps track of the position where the next unique element should be placed, while the other traverses the array. Whenever a new unique element is found, it is placed at the current unique position.

**Complexity:**  
- Time Complexity: O(n)
- Space Complexity: O(1)
