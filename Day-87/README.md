# 🚀 Day 87 – Dr. G. Vishwanathan 100 Days of Code Challenge

## 🧩 Problem Solved

### LeetCode
- **2904 – Shortest and Lexicographically Smallest Beautiful String**

## 🔑 Key Learnings

- Used the **Sliding Window** technique to find substrings containing exactly `k` ones.
- Maintained a count of `1`s while expanding and shrinking the window.
- Compared valid substrings based on:
  - Shortest length
  - Lexicographically smallest value when lengths are equal.
- Learned how to efficiently handle substring selection while maintaining window constraints.

## 🛠️ Concepts Practiced

- Sliding Window
- Two Pointers
- String Manipulation
- Lexicographical Comparison
- Frequency/Count Tracking
