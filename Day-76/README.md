## Problems Solved:

### 1. 3702. Longest Subsequence With Non-Zero Bitwise XOR

**Problem:**  
Find the length of the longest subsequence whose bitwise XOR is non-zero.

**My Approach:**  
Used the XOR of all elements to determine the answer. If the XOR of the complete array is non-zero, the entire array can be taken as the longest subsequence. If the XOR is zero, removing any non-zero element makes the XOR non-zero, so the answer becomes `n - 1`. If all elements are zero, no valid subsequence exists.

**Complexity:**  
- Time Complexity: O(n)
- Space Complexity: O(1)
